Project Grid Builder

Design the image grids for every project page — one tab per project, drag-and-drop your assets folder, export ready-to-use layouts.
How to use this: 1. Click a project tab below (Sprouts, Corita Art Center, SoCal Earth, Cultural Olympiad, Valley Strong Credit Union, More Work). 2. Option A: Start fresh: Build sections with + Add Section — name them in Title Case (e.g. "Times Square Advertisement"). Add rows, set aspect ratios. Then load assets folder (step 4) and assign images. 3. Option B: Import existing JSON: Paste a previously exported grid JSON into the Import JSON field at the bottom and hit Load JSON — your layout reconstructs with all section/row/aspect settings. The preview shows filenames in placeholder boxes. Then load the assets folder (step 4) to see actual images. 4. In the left panel, click Load Assets Folder and pick that project's folder from Desktop/portfolio/assets/<project> — every image AND video shows up as a thumbnail (videos are marked with a blue "VIDEO" badge). Once loaded, all cells with matching filenames will automatically display the images in the preview. 5. Assign images: drag a thumbnail from the left shelf onto a grid cell, or click a thumbnail to "arm" it then click the cell you want it in. For a single-image row, the box automatically resizes to match your photo's real shape — no cropping, no math, no typing numbers. A blue confirmation message flashes at the bottom when this happens. If a row's shape still looks wrong later, click the 📐 Match to Image button next to that row's Aspect Ratio dropdown to fix it again anytime. 6. Need an image or video smaller within its box (not filling the whole cell)? Use the Size slider under each assigned cell — 100% fills the cell edge-to-edge like normal, lower values shrink it and center it with white space around it. 7. Two images side-by-side and one looks squished or cropped? Hover the thin line between them in the preview — your cursor becomes a resize arrow — and drag it left/right until both photos look right. No JSON editing needed. 8. Want a photo shown at its full real shape with zero cropping, but the row is set to a different aspect ratio? Check the Fit box under that cell — the box height adjusts to match the photo instead of cropping it. 9. Your work is saved automatically in this browser (comes back if you close and reopen the tab). 10. When ready, hit Copy JSON (current project) or Copy JSON — All Projects at the bottom and send it to me. I'll wire it into the site.
